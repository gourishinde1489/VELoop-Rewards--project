## 📌 Project Overview

The goal of this project is to design an engaging **Mine & Earn** experience for the VELOOP Rewards app, helping users understand their mining progress, track rewards, and interact with the interface through a polished and motivating design.

The visual direction focuses on:
- Premium and modern aesthetics
- Sophisticated gamification
- Clear reward and progress indicators
- Trustworthy, fintech-inspired UI
- Interactive and user-friendly experiences

## 🎨 Visual Design Direction

The design uses a premium dark interface with a carefully balanced color palette.

| Color | Hex Code | Purpose |
|---|---|---|
| Midnight Navy | `#161827` | Primary background |
| Royal Slate | `#22263B` | Cards and panels |
| Antique Gold | `#B88A35` | Reward and achievement accents |
| Champagne Gold | `#E2C477` | Progress indicators and key highlights |
| Soft Gold | `#FFF0BC` | Metallic highlights |
| Trust Blue | `#82AFE8` | Technology accents and interactions |
| Warm Ivory | `#F3F1EB` | Headings and primary text |
| Silver Mist | `#A4ABC0` | Secondary text |
