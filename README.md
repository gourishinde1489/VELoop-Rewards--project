## 📌 Project Overview

The objective of this project is to design an engaging **Mine & Earn** experience that communicates the earning process through an intuitive interface, attractive visuals, and interactive elements.

The design focuses on:
- Premium and modern visual aesthetics
- Sophisticated gamification
- Clear mining progress and reward indicators
- Engaging visual storytelling
- Interactive user experience
- Fintech-inspired design language

## 🚧 Project Status: In Progress

The project is currently under development.

The desktop version of the Mine & Earn banner and its interactive prototype have been completed. Following feedback, I have further refined the visual presentation, incorporated improvements into the design, and continued enhancing the overall user experience.

I am actively working on the remaining components and design refinements.

## 🎨 Visual Design Direction

The visual language uses a premium dark interface with gold accents to communicate trust, achievement, and rewards.

| Color | Hex Code | Purpose |
|---|---|---|
| Midnight Navy | `#161827` | Primary background |
| Royal Slate | `#22263B` | Cards and panels |
| Antique Gold | `#B88A35` | Reward accents |
| Champagne Gold | `#E2C477` | Progress indicators and highlights |
| Soft Gold | `#FFF0BC` | Metallic highlights |
| Trust Blue | `#82AFE8` | Technology accents |
| Warm Ivory | `#F3F1EB` | Primary text |
| Silver Mist | `#A4ABC0` | Secondary text |
